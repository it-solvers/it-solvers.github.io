## 문서 규칙

- **이 문서는 `docs/spec-v1.0.md` 하나만 둔다.** 새 버전 파일을 만들지 않고 이 파일에 내용을 계속 추가하며, 이전 버전 파일(v0.90~v0.93)은 이 문서로 합친 뒤 지웠다. 내용이 크게 바뀌어도 파일은 바꾸지 않고 11장 변경 이력에 한 줄을 더한다.
- **추가하거나 고친 문장 끝에는 일자와 시간을 괄호 안에 적는다.** 예: `…를 추가했다. (2026-10-27 14:30)` 형식은 `(YYYY-MM-DD HH:MM)`이고 한국 시간이다. 시각이 없는 문장은 v1.0을 처음 정리한 2026-10-27 14:09 이전부터 있던 내용이다.
- 이 저장소는 그대로 사이트로 공개된다. `docs/`의 내용도 `https://itsolvers.co.kr/docs/...`로 열린다. **계정 ID, 비밀번호, 개인 연락처, 인증 정보는 쓰지 않는다.**

## 1. 개요

- 사이트: 아이티해결단(IT Solvers) 소개 사이트. **AI 중심** 소프트웨어·앱 개발, IT자산 공급, 컴퓨터·서버·NAS 구축을 소개하고, 기술 인사이트(직접 만든 도구와 업무 지식), 주요실적, 문의로 구성한다. 금융·리스는 "지금 다루는 분야"로 둔다.
- 기술: 정적 HTML, CSS, 약간의 JavaScript. 서버와 DB는 없다.
- 언어: 한국어가 기본이고 영문 페이지(`en/`)가 별도로 있다.
- 디자인 콘셉트: **모던 SaaS**(밝은 푸른 바탕, 블루·시안 포인트, 둥근 카드). 자세한 내용은 5장. (2026-11-02 21:00)
- 문의: 메인 페이지의 **문의 폼**(Web3Forms)과 이메일 주소 복사·메일 앱 열기 버튼(4.6).

### 4.6 문의 (`#contact`)

**구성:** 문의 폼(주 수단) → 이메일로 직접 보내기(보조 수단).

**문의 폼**
- 전송: Web3Forms(`https://api.web3forms.com/submit`)로 보낸다. 접근 키(access key)는 공개 키라서 `index.html`의 폼에 그대로 있다(이 문서에는 적지 않는다). **메일을 받는 주소는 Web3Forms 서비스 설정에 연결되어 있어 코드에 없다.** 사이트의 이메일 주소를 회사 도메인 주소로 바꾼 뒤에도 폼 메일이 예전 주소로 가고 있다면 Web3Forms에서 수신 주소를 직접 바꿔야 한다(10장).
- 입력: 이름(또는 회사·기관명), 답변받을 이메일, 문의 내용, 개인정보 수집·이용 동의(모두 필수). 숨은 스팸 방지 칸(`botcheck`)이 있다.
- 동작: JavaScript(`fetch`)로 전송해 페이지를 벗어나지 않고 결과를 보여 준다. 성공하면 입력칸을 비우고, 실패하면 이메일로 보내 달라고 안내한다.
- 전자계약서 소개 페이지의 "견적/시험 사용 신청"도 같은 Web3Forms 키와 필드를 쓴다(7장). 메일 제목으로 구분한다.

**보조 수단:** 이메일 주소를 보여 주고, 그 아래에 같은 크기의 두 버튼을 좌우로 나란히 둔다. **"이메일 주소 복사"**(클립보드 복사)와 **"메일 앱으로 열기"**(`mailto:`). 복사 결과 안내는 버튼 줄 아래에 나온다. 폰에서 설명 문장이 두 줄로 꺾이던 것을 줄여 버튼만 둔 것이다. 특정 메일 서비스(Gmail 등) 링크는 두지 않는다. 전자계약서 페이지(한글·영문)도 같은 구성이다.

**회사 이메일 주소:** 2026-10-27부터 사이트의 모든 이메일 표시를 회사 도메인 주소로 쓴다(네이버 주소 제거). 표시 위치는 메인 문의, 소개, 문의 안내, 개인정보처리방침, 전자계약서(한글·영문)와 메인의 구조화 데이터(`email`)다.

### 5.3 화면 밝기 자동 전환 (`js/theme.js`)
- **기본은 자동**이다. 인천 동인천역(북위 37.4752°, 동경 126.6329°) 기준 그날의 일출~일몰에는 밝게, 그 밖에는 어둡게 보인다. 일출·일몰 시각은 스크립트 안에서 계산하므로 외부 서비스나 위치 권한이 필요 없다(계산값: 2026-10-27 일출 06:52, 일몰 17:41 / 2026-01-01 07:48, 17:25).
- 사용자가 ☀ ☾ 버튼을 눌러 바꾸면 **다음 일출·일몰까지만** 유지하고 그 뒤에는 다시 자동이다. 저장값은 브라우저의 `theme`(dark/light)과 `themeUntil`(유지 종료 시각)이며 한글·영문 모든 페이지가 공유한다.
- 페이지를 열어 둔 채 일출·일몰이 지나면 화면이 저절로 바뀐다. 탭을 다시 보게 될 때도 갱신한다.
- 한글·영문 메인과 모든 서브페이지가 같은 `js/theme.js`를 쓴다. 메인의 버튼은 `window.SunTheme.toggle()`을 호출한다. 저장소 접근이 막혀 있어도 자동 판단은 동작한다.
- 방문자 위치와 무관하게 인천 기준이다(해외 접속자도 인천 일출·일몰에 맞춰진다).
- 이전의 "저장값이 없으면 어두운 화면이 기본" 규칙은 없어졌다. 낮에 처음 오면 밝은 화면이 먼저 보인다.

### 5.4 첫 화면 장식(호랑이 제거)
- 이전 첫 화면의 해·달·별·산·격자 무늬와 호랑이 그림은 없앴다. 호랑이를 빼면서 한글 메인 푸터의 공공누리 출처 문구도 뺐다(문구를 쓸 의무가 없어짐). `images/tiger.webp`와 원본 jpg는 저장소에 남아 있지만 쓰이지 않는다. 다시 쓰려면 출처 문구를 되살려야 한다. (2026-11-02 21:00)

### 5.5 진행순서(`#process`)
번호를 도장 같은 네모로 두고 선과 화살표로 잇는 단계 흐름이다(넓은 화면은 가로 한 줄, 좁은 화면은 세로 타임라인). 마우스를 올린 단계까지 번호가 채워지고 앞쪽 선이 실선이 된다(최신 브라우저의 `:has()`를 쓰며, 지원하지 않으면 효과 없이 기본 모양).

## 8. 소개·문의·개인정보 페이지와 검색(SEO)

### 8.1 소개 (`about.html`, `en/about.html`)
- "누가 운영하나요" 카드 오른쪽에 대표 캐릭터 그림(`images/ceo-avatar.webp`, 240px, 원본은 1440px)이 둥근 아이콘으로 들어 있다. 글은 왼쪽 칸에서만 줄바꿈되고 폰에서는 아이콘이 68px로 줄어든다. 한글·영문 모두 같다.
- 푸터에는 상호·대표·사업자등록번호만 두고, 맨 아래 한 줄에 소개·문의 안내·개인정보처리방침 링크를 둔다.

### 8.2 검색(SEO)과 분석
- 모든 페이지: `title`, `description`, `canonical`, `robots(index, follow)`, OG와 트위터 카드, JSON-LD. 검색용 문구는 2026-10-26에 "AI 중심" 방향으로 정리했다.
- 메인 페이지는 `hreflang`으로 한글/영문을 연결한다.
- **내부 링크는 메인을 `/`(한글), `/en/`(영문)으로 건다.** `index.html`로 직접 걸지 않는다. 구글 Search Console의 "적절한 표준 태그가 포함된 대체 페이지"(`/index.html`, `/en/index.html`) 항목이 이 때문에 생겼다. 표준 태그(`canonical`)는 이미 맞게 되어 있어 검색에는 영향이 없고, 알림은 남아 있을 수 있다.
- `sitemap.xml`: 현재 URL 26개(한글·영문 메인, 한글·영문 인사이트·MVP, 소개·문의·개인정보). 새 공개 페이지를 만들면 영문 항목을 한글 항목보다 앞에 두어 추가하고 수정일을 갱신한다.
- `robots.txt`: 전체 허용, 사이트맵 위치 명시.
- 분석과 광고: 구글 애널리틱스, 애드센스 스크립트가 모든 페이지에 들어 있다. 광고 단위는 따로 넣지 않았다.
- 소유 확인: 구글(메타 태그와 HTML 파일), 네이버(메타 태그).

## 10. 알려진 한계와 미결

- **문의 폼 수신 주소와 도메인 메일:** 사이트의 이메일 표시는 회사 도메인 주소로 바뀌었지만, 문의 폼(Web3Forms)이 메일을 보내는 주소는 서비스 설정에 따로 있다. 폼 수신 주소를 바꿨는지, 도메인의 MX(메일 수신) 설정이 되어 있어 실제로 수신되는지 **확인이 필요하다**(v0.92 시점에는 도메인 메일을 쓰지 않았고 MX 레코드도 삭제해 둔 상태였다).
- 문의 폼의 개인정보 안내문은 초안이다(보유 기간 등 실제 방침과 법률 검토 필요). 메인과 전자계약서 폼이 공통이라 한쪽을 고치면 다른 쪽도 확인한다.
- 문의 폼의 스팸 방지는 숨은 칸만 쓴다. 무료 한도(월 250건)와 서비스 조건은 바뀔 수 있다.
- 전자계약서의 요금과 법적 효력 관련 문구는 확정 전이다.
- **호랑이 원본:** `images/` 안의 원본 jpg(약 4.6MB, e뮤지엄 다운로드 파일)가 저장소에 올라가 있다. 사이트에서 쓰지 않으므로 저장소에서 빼도 된다(필요하면 e뮤지엄에서 다시 받을 수 있다).
- 구글 폰트(Noto Serif KR)를 외부에서 불러온다. 불러오지 못하면 시스템 명조체로 대신 보인다.
- 한글 메인에서 `index.html`의 열린 `<div>`가 닫힌 `<div>`보다 1개 많은 상태가 이전부터 있다(렌더링에는 문제가 없어 보이며 원인은 확인하지 않았다).
- 실제 폰 기기에서의 확인(호랑이 위치, 전자계약서 버튼 줄, 밝기 자동 전환)은 사용자 확인이 필요하다.
