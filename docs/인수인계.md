## 3. 글꼴과 모양

- **제목(h1~h3)과 섹션 라벨, 버튼, 날짜, 태그:** 코드 글꼴
  `ui-monospace, "SF Mono", Menlo, Consolas, "D2Coding", "Apple SD Gothic Neo", monospace`
  굵기 700, 글자 간격 `-0.03em`~`-0.04em`. 한글은 코드 글꼴에서 넓게 벌어져 보일 수 있습니다(제목만 일반 글꼴로 되돌리는 선택지가 있음).
- **본문:** 시스템 산세리프(`-apple-system, "Segoe UI", "Noto Sans KR", "Malgun Gothic", sans-serif`).
- **모서리:** 카드 10px, 버튼·입력칸 8px. **그림자 없음**(`box-shadow: none`). 선은 1px.
- **터미널 명령어 장식은 없습니다(2026-11-08 삭제).** 로고 뒤 `~ %`, 맨 위 프롬프트 석 줄, 맨 아래 커서 줄, 버튼 앞 `%`, 섹션 라벨 앞 `## `, 소개글 앞 `// `, 그룹 제목 앞 `── `를 모두 뺐고 코드 글꼴·초록·로그 창 모양 같은 스타일만 남겼습니다. 다시 넣지 않습니다.
- **한글 페이지는 한글을 우선**(메뉴·제목·안내 문구).

### 4.1 색 변수 블록 (그대로 붙여 넣기)

html:not(.dark-mode) {
  --t-bg:#f6f8fa; --t-bg2:#eef1f5; --t-soft:#f0f3f6; --t-card:#ffffff;
  --t-ink:#1f2328; --t-muted:#59636e; --t-line:#d0d7de;

  --t-glow:rgba(10,122,69,.07); --t-shadow:none;
  --t-head:rgba(246,248,250,.88); --t-foot:#ffffff; --t-foot-ink:#59636e;
}
html.dark-mode {
  --t-bg:#0b0e13; --t-bg2:#10151c; --t-soft:#121821; --t-card:#121821;
  --t-ink:#e6edf3; --t-muted:#8b98a9; --t-line:#232c38;

}
:root { --t-mono: ui-monospace,"SF Mono",Menlo,Consolas,"D2Coding","Apple SD Gothic Neo",monospace; }

### 4.2 첫 화면 조각

```html
<h1>업무를 아는 개발자가<br><span>웹·앱</span>을 만듭니다.</h1>   <!-- span만 초록 -->
<p class="hero-text">…</p>
<div class="hero-cta">                                               <!-- 3칸 격자, 같은 크기 -->
  <a class="button button-primary" href="#insights-mvp">직접 만든 앱 보기</a>
  <a class="button button-secondary" href="#insights-tools">리스 계산기</a>
  <a class="button button-secondary" href="#insights-knowledge">업무 지식</a>
</div>
… 새소식 …
```

- 버튼은 코드 글꼴 14px, 모서리 8px, 화살표·그림자 없음. 주 버튼만 초록 채움. 호버 시 2px 떠오름과 테두리 초록.
- 새소식은 "로그 창" 모양: 제목줄(바탕2 + 아래 선), 줄 단위 목록, 줄에 호버하면 바탕2.
- 폰(520px 이하): 버튼 글자 12.5px, 안쪽 여백 축소. 400px 이하는 더 줄임.

### 4.3 카드: 벤토(Bento) 격자

6칸 격자(`grid-template-columns: repeat(6, 1fr)`), 간격 16px.
- 카드 4개: 1·4번 4칸, 2·3번 2칸.
- 카드 3개: 1번이 왼쪽에서 2줄 높이, 2·3번이 오른쪽에 쌓임.
- 그 외 개수: 모두 3칸(2열).
- 폭 800px 이하: 한 줄에 한 장.
- **주의:** 폰용 규칙은 칸 수 규칙보다 우선순위가 같거나 높아야 합니다(`:nth-child(n):nth-last-child(n)`으로 맞춤). 이걸 놓치면 폰에서 카드가 세로로 찌그러집니다.

### 4.4 로고

- 밝은 화면: 투명 로고 `images/logo-light.png`(480×252, "IT" 마크만. 원본 `아이티해결단_로고_투명.png`에서 마크만 잘라 씀).
- 어두운 화면: 기존 `images/logo.png` + 흰 배경 칩(`background:#fff; border-radius:8px; padding:2px 4px`).
- 방법: `.logo-mark`에 밝은 화면일 때 배경 이미지를 깔고 `<img>`는 `opacity:0`(자리·alt 유지). 영문 메인만 `<img>` 두 장(`logo-dark`/`logo-light`)을 CSS로 번갈아 보임.

## 5. 밝은/어두운 전환 방식 (`js/theme.js`)

- `<head>`에서 즉시 실행해 깜빡임을 막고, `html`에 `dark-mode` 클래스를 붙이거나 뗍니다.
- 기본은 **자동**: 인천 동인천역(37.4752°N, 126.6329°E) 기준 그날 일출~일몰에는 밝게, 그 밖에는 어둡게. 계산은 파일 안에서 하므로 외부 서비스·위치 권한이 필요 없습니다.
- 사용자가 ☀ ☾를 누르면 **다음 일출·일몰까지만** 유지(`localStorage`의 `theme`, `themeUntil`). 한글·영문 모든 페이지가 공유.
- 밝기를 따로 저장하거나 기본값을 어둡게 고정하는 코드를 다시 넣지 않습니다(CLAUDE.md 규칙).
- 다른 프로젝트에 옮길 때는 `js/theme.js`를 그대로 복사하고 `html.dark-mode`로 색 변수를 바꾸는 CSS(4.1)만 붙이면 됩니다.

## 7. 다른 곳에 적용하는 방법

### 7.1 버셀 앱 (React 웹)

앱 저장소가 이 폴더에 없어서 **제가 직접 확인하지 못했습니다.** 아래는 일반적인 방법입니다.

1. 앱 전체 CSS(또는 전역 스타일 파일)에 **4.1의 색 변수 블록**을 붙입니다.
2. 앱의 배경·글씨·카드·버튼·입력칸 색을 변수(`var(--t-bg)` 등)로 바꿉니다. 이미 CSS 변수나 테마 객체(styled-components, MUI 등)가 있다면 값만 위 표로 바꿉니다.
3. 제목에 코드 글꼴(`--t-mono`), 카드 모서리 10px, 버튼 8px, 그림자 없음.
4. 밝은/어두운 전환: `js/theme.js`를 그대로 가져다 `index.html`의 `<head>` 맨 위에 넣거나, React에서 같은 로직을 쓰고 `document.documentElement.classList.toggle('dark-mode')`.
   (`prefers-color-scheme`만 쓰면 사이트의 일출·일몰 자동 전환과 다르게 동작합니다. 사이트와 맞추려면 `js/theme.js`를 쓰세요.)
5. 로고: 밝은 화면 `logo-light.png`, 어두운 화면 `logo.png`(흰 칩). 두 이미지를 앱에도 복사.
6. (로고 뒤 `~ %` 같은 명령어 장식은 쓰지 않습니다.)
7. 배포 후 밝은/어두운 두 화면에서 글자 대비 확인.

### 7.2 React Native 앱

CSS가 없으므로 같은 값을 테마 객체로 만듭니다.

```ts
export const terminal = {
  dark:  { bg:'#0b0e13', bg2:'#10151c', card:'#121821', line:'#232c38', ink:'#e6edf3', muted:'#8b98a9', ac:'#3fdc8a', acInk:'#04130b', ac2:'#5cc8ff' },
  light: { bg:'#f6f8fa', bg2:'#eef1f5', card:'#ffffff', line:'#d0d7de', ink:'#1f2328', muted:'#59636e', ac:'#0a7a45', acInk:'#ffffff', ac2:'#0b63c4' },
  mono: Platform.select({ ios:'Menlo', android:'monospace' }),
  radius: { card:10, button:8 },
};
```

- 밝기 전환은 `useColorScheme()`(폰 설정을 따름)이 가장 간단하고, 사이트처럼 일출·일몰 자동 전환이 필요하면 `js/theme.js`의 일출·일몰 계산식을 옮겨야 합니다(필요 여부는 사용자가 정할 일).
- 그림자는 쓰지 않습니다(`elevation: 0`, `shadowOpacity: 0`).
- 한글 글꼴이 코드 글꼴로 넓게 벌어져 보이면 제목만 일반 글꼴로 되돌립니다.
- 제가 React Native 앱 코드를 본 적이 없어서, 위는 설계 예시입니다.

### 7.3 완전히 새 프로젝트

4.1 색 변수 블록 + 3장 글꼴·모양 + 4.2 첫 화면 조각 + 5장 `js/theme.js`만 가져가면 같은 모양이 나옵니다.

## 9. 조심할 점 (이번 작업에서 겪은 것)

1. **CSS 우선순위:** `theme.css`는 `:root:root:root …` 식으로 우선순위를 크게 올려 둡니다. 덮어쓰는 규칙도 같은 접두어를 붙여야 이깁니다(`theme-terminal.css`, 벤토 폰 규칙).
2. **브라우저 캐시:** CSS를 고치고 `?v=`를 그대로 두면 옛 CSS가 남습니다. **CSS를 고칠 때마다 모든 페이지의 `?v=`를 올립니다**(값만 달라지면 됩니다. 예 `20261107-1810`. 뒤 숫자는 시각이 아니라 구분용 번호).
3. **용어 사전:** 자체 `<style>`을 쓰므로 `theme-sub.css`만 고치면 안 바뀝니다. 파일 안 변수도 같이 바꿉니다. 예시 카드 안의 색은 일부러 다양합니다.
4. **전자계약서:** 전용 테마 파일이 두 개 더 있습니다.
5. **스크립트 오류는 없었지만** 헤드리스 확인에서 어두운 화면은 `localStorage`로 강제해서 봤습니다. 실제 기기의 어두운 화면은 푸시 후 직접 확인이 필요합니다.
6. **영문 페이지:** 영문 메인은 별도 테마 파일(`theme-en.css`)이고 영문 소개·문의는 한글과 같은 `theme-terminal.css`를 씁니다.
7. **개인 정보:** 화면에 본인 컴퓨터 이름·계정명(`dlgurpro`, 호스트 이름)을 쓰지 않습니다.
8. **계산 코드는 바꾸지 않습니다.** 테마 작업은 CSS와 화면 문구만 건드렸습니다(CLAUDE.md 규칙).

3. **터미널 명령어 장식 삭제:** 6장 파일들(`theme-terminal.css`, `theme-sub.css`, `theme-en.css`)의 `~ %`, `%`, `## `, `// `, `── ` 와 메인 HTML의 프롬프트 석 줄·커서 줄 제거. 스타일(코드 글꼴, 초록, 로그 창)은 유지.
4. **다크 입력칸 테두리:** 어두운 화면에서 입력칸 테두리가 바탕과 거의 같아 안 보였음 → 테두리를 `#5b6a7e`(바탕과 약 3:1)로 통일. 적용 파일: `theme-terminal.css`(문의 폼), `theme-sub.css`(서브페이지 입력·선택·텍스트칸), `theme-en.css`, `theme-econtract.css`, 용어 사전 두 파일(자체 `<style>`). 옛 `dark.css`·`dark-econtract.css`는 `#6b7280`. 입력칸에 포커스하면 초록 테두리. **새 입력칸을 만들면 다크 화면 테두리를 이 값으로 합니다.**
5. **캐시 번호:** 위 CSS를 고칠 때마다 모든 페이지의 `?v=`를 올렸음(`20261108-1`~`-3`). 9장 2번 규칙대로 계속 올립니다.
