리스료 계산기

차량대금, 리스 기간, 연 금리, 만기 잔가를 넣으면 월 리스료를 계산해 줘요.

리스료 계산 공식과 엑셀·구글 시트 PMT 함수

계산 조건을 입력하고 계산 버튼을 누르면 아래 코드로 월 리스료를 계산합니다.

월 리스료 계산 버튼에서 실행되는 코드

const monthlyRate = annualRate / 100 / 12;
const monthlyPayment = monthlyRate === 0
  ? (vehiclePrice - residualValue) / termMonths
  : (vehiclePrice - residualValue / Math.pow(1 + monthlyRate, termMonths)) *
    monthlyRate / (1 - Math.pow(1 + monthlyRate, -termMonths));

Java·JavaScript·Python 계산식 예제

아래 함수는 페이지의 계산 버튼과 같은 월 리스료 산식을 사용합니다. 연 금리는 퍼센트 값(예: 5는 5%)으로 전달하고, 잔가는 보증잔가와 무보증잔가의 합으로 입력합니다.

Java 코드 보기 
static double calculateLeasePayment(
    double vehiclePrice,
    int termMonths,
    double annualRatePercent,
    double residualValue
) {
    double monthlyRate = annualRatePercent / 100.0 / 12.0;
    if (monthlyRate == 0.0) {
        return (vehiclePrice - residualValue) / termMonths;
    }

    return (vehiclePrice
        - residualValue / Math.pow(1.0 + monthlyRate, termMonths))
        * monthlyRate
        / (1.0 - Math.pow(1.0 + monthlyRate, -termMonths));
}
JavaScript 코드 보기 
function calculateLeasePayment(
  vehiclePrice,
  termMonths,
  annualRatePercent,
  residualValue
) {
  const monthlyRate = annualRatePercent / 100 / 12;
  if (monthlyRate === 0) {
    return (vehiclePrice - residualValue) / termMonths;
  }

  return (vehiclePrice
    - residualValue / Math.pow(1 + monthlyRate, termMonths))
    * monthlyRate
    / (1 - Math.pow(1 + monthlyRate, -termMonths));
}
Python 코드 보기 
def calculate_lease_payment(
    vehicle_price,
    term_months,
    annual_rate_percent,
    residual_value,
):
    monthly_rate = annual_rate_percent / 100 / 12
    if monthly_rate == 0:
        return (vehicle_price - residual_value) / term_months

    return (
        vehicle_price
        - residual_value / (1 + monthly_rate) ** term_months
    ) * monthly_rate / (1 - (1 + monthly_rate) ** -term_months)
  • 연 금리가 0%이면 월 리스료 = (차량대금 − 만기 잔가) ÷ 개월 수로 계산합니다.

엑셀·구글 시트 PMT 함수 예시

예를 들어 A1에 차량대금, A2에 리스 기간(개월), A3에 연 금리(%), A4에 만기 잔가를 입력했다면:

=PMT(A3/100/12, A2, -A1, A4)

차량대금은 현재 지급하는 금액이라 음수(-A1)로, 만기 잔가는 마지막에 회수되는 금액이라 양수(A4)로 입력합니다. PMT의 기본 지급 시점은 매월 말이며, 위 식은 계산기와 같이 월 금리를 연 금리의 12분의 1로 계산합니다. 월초 납부 조건이나 별도 수수료·보험료·세금이 있으면 결과가 달라집니다.

계산 조건

월 리스료
월 원금 (첫 달)
월 이자 (첫 달)
전체 리스료
전체 원금
전체 이자

월 원금과 월 이자는 첫 달 기준입니다. 전체 원금은 월 리스료로 상환하는 원금(차량대금 − 만기 잔가)이며, 전체 이자는 전체 리스료에서 전체 원금을 뺀 금액입니다. 만기 잔가는 전체 원금에 포함되지 않으며, 이 계산은 금융리스·운용리스의 회계상 수익인식액을 나타내지 않습니다. 보험료·자동차세·수수료 및 세금은 제외한 참고용 계산입니다.
