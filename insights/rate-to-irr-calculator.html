리스 금리로 IRR 계산하기

금리로 월 리스료를 산출한 뒤, 보험료·자동차세의 고객 수납과 실제 연간 납부 현금흐름을 반영해 IRR을 계산합니다.

계산 방식

입력한 연 금리를 12로 나눠 월 금리로 바꾸고, 보증잔가와 무보증잔가를 각각 반영해 월 리스료를 계산합니다.

현금흐름에는 차량가격의 초기 유출, 매월 리스료와 보험료·자동차세 수납액, 지정한 월의 보험료·자동차세 연간 납부액, 계약 종료 시 잔가 유입을 반영합니다.

월 IRR은 현금흐름의 순현재가치(NPV)가 0이 되는 월 수익률입니다. 이 페이지는 이분법으로 월 IRR을 구한 뒤 (1 + 월 IRR)12 − 1로 연 환산합니다.

이 계산기는 입력 조건에 따른 현금흐름 분석용 참고 도구입니다. 실제 계약 조건이나 금융리스·운용리스의 회계상 수익인식을 의미하지 않습니다.

계산 조건

1~12월 중 연 보험료를 실제 납부하는 월
1~12월 중 자동차세를 실제 납부하는 월

월별 현금흐름과 IRR 계산

(−)는 현금 유출, (+)는 현금 유입입니다. 보험료와 자동차세는 고객에게 매월 12분의 1씩 수납하고, 실제 납부월에는 연간 금액 전액을 유출로 표시합니다.

JavaScript 계산 코드

아래 예제는 입력한 금리로 월 리스료와 현금흐름을 만들고, 월 IRR을 이분법으로 계산해 연 환산하는 핵심 구조입니다.

코드 예제 펼쳐 보기 
function calculateIRR(cashFlows) {
  function npv(monthlyRate) {
    return cashFlows.reduce(
      (sum, cashFlow, month) => sum + cashFlow / (1 + monthlyRate) ** month,
      0
    );
  }

  let low = -0.9;
  let high = 10;
  const lowNpv = npv(low);
  const highNpv = npv(high);
  if (!Number.isFinite(lowNpv) || !Number.isFinite(highNpv) ||
      (lowNpv > 0) === (highNpv > 0)) {
    return null;
  }

  for (let i = 0; i < 500; i++) {
    const mid = (low + high) / 2;
    if (npv(mid) > 0) low = mid;
    else high = mid;
  }
  return (low + high) / 2;
}
