웹 UI 용어 사전 Web UI Glossary

용어마다 핵심 문법 표, 직접 눌러 볼 수 있는 예시, 복사해서 쓰는 코드를 한 카드에 담았습니다. 필요할 때 위의 검색창에 한글이나 영어로 입력해 찾으세요.

공통 용어 보기
UI
User Interface, 사용자가 눈으로 보고 누르는 화면 구성
HTML
HyperText Markup Language, 화면의 구조를 적는 언어
CSS
Cascading Style Sheets, 화면의 모양과 배치를 정하는 언어
JavaScript
자바스크립트, 화면에 동작을 넣는 언어
SVG
Scalable Vector Graphics, 확대해도 깨지지 않는 벡터 그림 형식
Canvas
캔버스, 자바스크립트로 점과 도형을 직접 그리는 영역
ARIA
Accessible Rich Internet Applications, 화면 낭독기 같은 보조 기술에 역할과 상태를 알려 주는 속성
FPS
Frames Per Second, 1초에 화면이 갱신되는 횟수
CDN
Content Delivery Network, 라이브러리 파일을 빠르게 내려받게 해 주는 배포망

기준 브라우저: Chrome(크롬) — 이 페이지의 모든 예시는 Chrome 기준으로 동작하도록 만들었고 직접 열어 확인했습니다. 아래 브라우저별 버전 숫자는 Safari·Firefox까지 쓸 때 참고하는 정보이며, Chrome만 쓰신다면 못 쓰는 기능은 없습니다. (Chrome 최신 버전 기준)

  • 브라우저 지원 범위(확인함): backdrop-filter는 Chrome 76, Edge 79, Firefox 103, Safari 18부터이며 2024-09-16부터 Baseline(베이스라인, 주요 브라우저에서 모두 쓸 수 있다는 웹 표준 지표) 중 신규 제공 단계입니다. 컨테이너 쿼리는 Chrome·Edge 105, Firefox 110, Safari 16부터이며 2025-08-14부터 폭넓게 제공 단계입니다. CSS linear()는 Chrome·Edge 113, Firefox 112, Safari 17.2부터입니다. Intl.Segmenter는 Chrome·Edge 87, Safari 14.1, Firefox 125부터입니다. 출처: Web Features Explorer의 backdrop-filter, 컨테이너 쿼리, linear(), Intl.Segmenter 페이지.
  • offset-path(모션 패스)는 caniuse 기준 Chrome 46, Edge 79, Firefox 72, Safari 16부터입니다(caniuse). 다만 path() 함수 형식의 세부 지원은 자료에 없어 확인 필요.
  • View Transitions(화면 전환 기능)는 같은 페이지 안에서 Chrome·Edge 111, Safari 18, Firefox 144부터입니다(Chrome for Developers). 페이지 간 이동 전환은 Chrome이 2024년에 제공했고 Safari도 지원한다고 하나, Firefox 상태와 정확한 버전은 자료에 없음. details의 name 속성은 Chrome·Edge 120, Firefox 130, Safari 17.2부터입니다(Chrome for Developers). 스크롤 연동 애니메이션은 Chrome·Edge 115, Safari 26부터이고 Firefox는 기술 미리보기로 표기되어 있습니다(Chrome for Developers). MDN은 제한적 제공으로 표기하므로 Firefox 정식 지원 여부는 확인 필요(MDN).
  • 라이브러리와 도구: flubber는 최신 버전 0.4.2가 2018년 3월 것이고 Snyk 평가에서 비활성으로 분류됩니다(Snyk). canvas-confetti는 jsDelivr 기준 최신 1.9.4입니다(jsDelivr). 다만 cdnjs 등록 여부와 실제 파일 경로는 확인하지 못했습니다. cubic-bezier.com은 Lea Verou의 2011년 글에서 소개된 도구이며, 현재 접속 가능 여부는 확인하지 못했습니다.
  • 시간 기준: Material Design 1 문서는 데스크톱 150~200ms, 모바일 약 300ms, 크고 복잡한 전체 화면 전환 375ms, 들어오는 요소 225ms, 나가는 요소 195ms로 안내합니다(m1.material.io). 이 외의 시간 수치(스태거 60~100ms, 마이크로 인터랙션 0.1~0.4초 등)는 경험적인 값이며 출처가 없습니다.
  • Toast(토스트)와 Snackbar(스낵바): Material Design 1(구글의 디자인 가이드 1세대) 내용을 옮긴 mdui 문서는 둘을 다른 컴포넌트로 구분합니다. 스낵바는 작업 결과를 알리고 버튼을 하나 둘 수 있으며, 토스트는 Android 시스템 메시지용이고 상호작용이 없습니다. 이전에 같은 뜻으로 묶었다고 한 설명은 정정합니다. 이 자료는 원문이 아니라 옮긴 문서이고, 웹 라이브러리마다 용어 사용이 다를 수 있어 확인 필요.
  • 2026-11-02에 추가한 51개 카드(화면 구조 · 네비게이션 · 상태/폼 · 렌더링/배치 · 인터랙션 · 성능): MDN, React 공식 문서, Web Features Explorer에 접속할 수 없어 이번에는 원문으로 사실을 대조하지 못했습니다. 그래서 브라우저 버전 숫자는 넣지 않았고, 동작은 Chrome(Chromium)에서 직접 열어 눌러 보며 확인했습니다. 모바일 기기의 실제 터치·진동·안전 영역 값은 확인하지 못했습니다.
  • 특히 확인 필요: React ErrorBoundary와 제어/비제어 컴포넌트의 세부 규칙, SWR(HTTP 캐시 확장 RFC 5861과 같은 이름의 라이브러리)의 정확한 동작, 햅틱(navigator.vibrate)의 iOS·데스크톱 지원과 사용자 조작 조건, 아코디언의 interpolate-size, 당겨서 새로고침과 브라우저 기본 동작의 충돌, 호버 의도 시간 같은 숫자(경험적 값).
  • 코드는 이해를 돕기 위해 줄인 예시입니다. 실제 서비스에 넣기 전 접근성 검사와 기기별 시험은 별도로 확인 필요.
  • 통계, 인용, 출처가 필요한 수치는 이 문서에 넣지 않았습니다. 화면에 보이는 숫자와 문장은 모두 예시입니다.
